# Datasets — Introdução à Bioestatística

Este repositório reúne os **datasets utilizados nas aulas da disciplina Introdução à Bioestatística**, do **Programa de Pós-Graduação em Oncologia (PPGO) do Instituto Nacional de Câncer (INCA)**.

Os conjuntos de dados disponibilizados neste repositório serão utilizados nas atividades práticas da disciplina, com o objetivo de apoiar o aprendizado dos principais conceitos e métodos de **bioestatística e análise de dados utilizando R**.

## Conteúdo

Os datasets incluem dados utilizados para exercícios e exemplos abordados ao longo das aulas, permitindo aos alunos reproduzir as análises realizadas em sala e desenvolver atividades práticas.

## Uso dos dados

Os arquivos deste repositório destinam-se às atividades acadêmicas da disciplina. Os alunos podem realizar o download dos datasets e utilizá-los para acompanhar as aulas, reproduzir os exemplos e desenvolver os exercícios propostos.
